## 🚀 Projetos em Destaque

### 1. IMAGINART (PI1 e PI2)
* **O que é:** Uma startup fictícia de produtos personalizados (cases e garrafas térmicas) focada em exclusividade utilizando Inteligência Artificial.
* **Competências Desenvolvidas:** Análise de mercado, SWOT, jornada do cliente, Design Thinking, prototipagem (MVP) e criação de Dashboards Operativos para acompanhamento de receitas e controle de estoque.
* **Ferramentas:** Power BI, Business Model Canvas, Matriz SWOT.

### 2. Automatização do PGA - Fatec Votorantim (PI3 e PI4)
* **O que é:** Um sistema web de ponta a ponta construído para automatizar a extração de dados não-estruturados (PDFs) do Plano de Gestão Anual da faculdade, transformando-os em um Dashboard analítico e centralizado.
* **Competências Desenvolvidas:** Construção de pipeline ETL, extração de dados com OCR/Visão Computacional, modelagem de banco NoSQL e desenvolvimento de interfaces web.
* **Ferramentas:** Python (`pdfplumber`), Node.js, Next.js 13+ (App Router), React, TypeScript, Tailwind CSS e MongoDB.
