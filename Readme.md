# Portfólio do Trabalho de Graduação

Peterson Alves Pereira · Fatec Votorantim · 2024–2026

Curso Superior de Tecnologia em Ciência de Dados para Negócios

Meu Trabalho de Graduação reúne a trajetória dos seis Projetos Integradores. Comecei pela análise de um negócio fictício, apliquei engenharia de dados a um problema da Fatec e, nos dois últimos semestres, trabalhei com a previsão de crescimento de um canal do YouTube.

## Projetos Integradores

| Projeto | Trabalho desenvolvido | Evidência |
| --- | --- | --- |
| PI1 · IMAGINART | Concepção de um negócio fictício de produtos personalizados, com análise de mercado e definição da proposta de valor. | [Relatório do PI1](02_Evidencias_PI/PI1_Negocios_Imaginart/PI1_Imaginart.pdf) |
| PI2 · IMAGINART | Continuidade do projeto de negócio, com dados simulados e painéis de indicadores em Power BI. | [Relatório do PI2](02_Evidencias_PI/PI2_Visualizacao_Imaginart/PI2_Imaginart_Power_BI.pdf) |
| PI3 · Plano de Gestão Anual da Fatec | Diagnóstico da extração manual de indicadores e protótipo de um painel para consultar dados dos documentos analisados. | [Diagnóstico do PI3](02_Evidencias_PI/PI3_Analise_PGA/PI3_Diagnostico_PGA.pdf) |
| PI4 · Dashboard PGA | Evolução do protótipo em uma aplicação com extração de PDFs em Python, armazenamento em MongoDB e visualização web. | [Apresentação do PI4](02_Evidencias_PI/PI4_Automacao_PGA/PI4_Dashboard_PGA.pdf) |
| PI5 · Sítio da Vovó Lúcia | Comparação de modelos de séries temporais e construção de um painel para estimar quando o canal poderia atingir 100 mil inscritos. | Relato no TG |
| PI6 · Sítio da Vovó Lúcia | Continuidade da previsão de inscritos, com dados do YouTube Analytics e avaliação temporal. Os notebooks também exploraram cenários condicionados a hipóteses sobre as visualizações futuras. | Relato no TG |
